## 1. 바로 열어보기

| 환경 | 방법 |
|---|---|
| 컴퓨터·아이패드 | `project-doha/index.html`을 더블클릭(또는 브라우저로 드래그) |
| 아이폰 | 파일 앱에서 `index.html`을 열고, 미리보기에서 화면이 반응하지 않으면 **공유 → Safari에서 열기** |

- 이미지 4장과 그림체 미리보기 8장이 **파일 안에 base64로 내장**되어 있어, 파일만 옮겨도 그림이 깨지지 않습니다. (약 630KB)
- 인터넷 연결이 없어도 됩니다. 광고·추적·외부 요청 없음.
- 저장한 기록은 그 브라우저의 로컬 저장소(`localStorage`)에만 남습니다. 파일을 지우거나 브라우저 데이터를 비우면 사라집니다.

## 2. v0.1에 들어 있는 것

**화면 1 · 홈**
- 가제/슬로건, 오늘의 그림체 8종 선택(3D 애니메이션 · 동화책 · 클레이 · 블록 월드 · 모험 만화 · 실사 영화 · 크레파스 · 픽셀 월드)
- "상상 시작하기" — 이야기를 만들다 만 상태면 "이어서 상상하기"로 바뀜

**화면 2 · 실시간 상상 캔버스 (핵심 체험)**
- 장면이 부드럽게 크로스페이드되고 천천히 줌되는 캔버스(켄번즈)
- 마이크 파형(마이크 허용 시 실제 입력 레벨, 거부/미지원 시 부드러운 시뮬레이션)
- 도하가 말할 법한 프롬프트 칩 8종 + 직접 입력창
  - 칩/입력 → "장면을 그리는 중" → 새 장면이 쌓이고 자막이 바뀜
  - `더 크게` `보라색` `우주선` `치즈 달` `만화처럼` 같은 말이 장면·색·그림체를 실제로 바꿈
- 상단 안전 배지("가족만 볼 수 있어요"), 그림체 배지(눌러서 즉시 변경), 경과 시간, "이야기 끝내기 →"
- 마이크를 허용하면 **그 순간의 목소리가 그 장면에 저장**되어 영화에서 함께 재생됨

**화면 3 · 상상 영화 (MY MOVIE)**
- 인트로 크레딧 → 장면별 자막 타임라인 자동 재생 → 엔딩 카드
- 재생/일시정지, 진행바 스크럽, 장면 점 표시
- "도하의 오늘의 한 줄", 오늘의 열쇠말 태그
- **아빠를 위한 관찰 노트**: 진단·점수 없이 오늘 나눈 말만 보고 쓴 관찰 + 도하에게 물어볼 질문 3개 + "이 노트는 심리 진단이 아니에요" 고지
- 아빠의 기록(한 줄 메모) → 기록에 함께 저장

**화면 4 · MY UNIVERSE**
- 날짜별 상상 영화 카드(샘플 3편 + 오늘 만든 것), 새 상상 만들기 카드
- **THE YEAR BOOK 미리보기** (12개월 진행 표시)
- **TIME CAPSULE** (1년 뒤 · 크리스마스, D-day 자동 계산)

## 3. 무엇이 진짜이고 무엇이 흉내인가 (v0.1 기준)

| 요소 | v0.1 |
|---|---|
| 화면·인터랙션·기록 저장 | 실제 동작 |

| 음성 인식(STT) | 없음 — 마이크는 파형과 목소리 녹음까지만 |

| 영상 합성·목소리 입히기 | 없음 (v0.4) — 재생은 장면 슬라이드 + 원본 목소리 클립 |

즉 **"상상을 말하면 화면이 반응하고, 끝나면 영화와 기록이 남는다"**는 핵심 흐름만 실제로 만져볼 수 있게 만든 버전입니다.

## 4. 파일 구조

```
project-doha/
  index.html                 ← 최종 산출물 (이미지 내장, 단일 파일)
  assets/
    scene1_livingroom.png    ← 생성 원본 4장 (1672×941)
    scene2_space.png
    scene3_giant.png
    scene4_spaceship.png
    web/                     ← 내장용으로 줄인 JPEG + 그림체 미리보기 8장
  src/
    index.src.html           ← 원본 소스 ({{IMG_*}}, {{T_*}} 자리표시자)
    prepare_assets.py        ← 원본 PNG → 웹용 JPEG + 그림체 썸네일 생성
    build.py                 ← 소스를 base64 내장 단일 index.html로 빌드
    check.py                 ← 3개 화면 크기에서 전체 흐름 자동 점검 + 스크린샷
    test2.py                 ← 그림체 시트·마이크·영화 종료·앨범 저장 점검
    shots.py                 ← 검토용 스크린샷 촬영
```

### 수정하는 방법

1. `src/index.src.html` 수정 → `python3 project-doha/src/build.py`
2. 그림체 썸네일·이미지를 바꾸려면 `python3 project-doha/src/prepare_assets.py` 먼저 실행 후 빌드
3. 문구·색·장면을 바꾸는 곳은 `index.src.html`의 `STYLES` / `CHIPS` / `SCENE_INFO` / CSS 변수(`:root`)

## 5. 도하와 써볼 때 체크할 것 (대화의 검증 5가지)

1. 도하가 시키지 않아도 다음 장면을 말하는가
2. 자기 상상이 화면이 되는 걸 재미있어 하는가 (어떤 그림체에서 오래 머무는가)
3. 대화가 더 풍성해지는가 (아빠가 끼어들 여지가 있는가)
4. 끝난 기록을 다시 보고 싶어 하는가
5. 다른 부모가 돈을 낼 것 같은가

## 7. 안전·개인정보 원칙 (v0.1에서 지킨 것)

- 광고·외부 링크·보상 시스템 없음
- 심리 진단·점수·평가 문구 없음 ("이 노트는 심리 진단이 아니에요" 상시 표시)
- 아이의 상상을 검열하지 않음 — 엉뚱한 말도 그대로 장면이 됨
- 모든 데이터는 기기 안에만 저장, 서버 전송 없음
- 이미지·목소리는 이 파일 밖으로 나가지 않음
