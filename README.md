# PROJECT DOHA — v0.1.2 터치 프로토타입

아이가 어른과 함께 화면을 눌러보며 **“상상이 화면이 되는”** 경험을 확인하는 웹앱 프로토타입입니다.

**아이는 자라고, 상상은 남습니다.**

- 제품 방향과 브랜드 철학은 [마스터 기획서](docs/MASTER_BRIEF.md)에 있습니다.
- 개발 지침은 [AGENTS.md](AGENTS.md), 작업 범위는 [첫 스프린트](docs/FIRST_SPRINT.md)에 있습니다.
- 공개 사이트는 [GitHub Pages](https://stellingyw-oss.github.io/Project-doha/)에서 `main` 루트 기준으로 배포합니다. 주소 경로의 `Project-doha`는 대문자 P를 사용합니다.

## 실행과 개발

`index.html`에 HTML·CSS·JavaScript와 예시 이미지가 들어 있습니다. 별도 빌드나 서버 의존성이 없습니다. 마이크 검증은 HTTPS 또는 로컬 HTTP 서버에서 실행하세요.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 마이크 권한 없이도 문장을 직접 입력할 수 있습니다.

## v0.1.2 기능

- 보호자와 아이의 동의를 확인한 뒤 녹음을 시작합니다. 녹음을 끄거나 화면을 떠나면 마이크 트랙을 해제합니다. 녹음한 구간은 원본 형식으로 보관합니다.
- 첫 화면은 비어 있으며, 입력한 문장은 그대로 남습니다. 예시 장면과 그림체 필터는 별도로 표시합니다. 자동 음성 자막과 생성형 이미지·영상은 아직 구현하지 않았습니다.
- MY UNIVERSE에서 기록마다 원본 녹음을 재생·다운로드하고, 기록 정보만 또는 원본 녹음을 포함한 JSON을 내보낼 수 있습니다. 삭제할 때는 확인을 요청합니다. 아빠의 기록은 저장 버튼으로 남깁니다.
- 부모 공간에는 직접 입력한 문장 수와 재생 가능한 녹음 구간 수, 열린 질문이 표시됩니다.

## 저장과 복구

작품과 원본 오디오는 브라우저의 IndexedDB(`doha-universe`, `works`·`clips` 스토어)에 저장합니다. 앱은 커밋 뒤 기록과 해당 작품의 오디오 구간 ID를 다시 확인합니다. 브라우저 데이터를 지우면 기록을 잃을 수 있습니다. 브라우저 또는 사이트 주소를 바꾸기 전에 파일을 내보내 따로 보관하세요. 내보내기는 브라우저 안에서 이루어지며 서버에 업로드하지 않습니다.

- **저장 확인**: 작품과 저장할 원본 구간이 확인되었습니다.
- **텍스트 기록만 또는 일부 저장**: 앱이 보조 저장소 사용 또는 누락된 구간을 알립니다. 실패 화면에서 다시 저장하거나 현재 메모리에 남은 원본을 파일로 내보낼 수 있습니다.
- **저장 실패**: 앱이 앨범에 새 성공 기록을 추가하지 않습니다. 새 이야기로 전환하거나 탭을 닫기 전에 복구 파일을 내려받으세요.
- 기존 IndexedDB 스키마와 `clipId`를 읽는 방식을 유지합니다. v0.1의 `localStorage` 원본은 이관 대상 작품이 IndexedDB에서 모두 확인된 뒤에만 삭제합니다.
- `doha.work/1` JSON에는 작품 정보, 직접 입력한 문장, 원본을 포함해 내보낸 경우 Base64 녹음과 구간 수가 들어갑니다. 파일에서 앱으로 복원하는 기능은 아직 구현하지 않았습니다. 내보낸 파일에 목소리나 입력 문장이 들어 있을 수 있으니 가족이 관리하는 곳에 보관하세요.

## 회귀 테스트

Python에 Playwright가 설치되어 있고 시스템 Chromium을 사용할 수 있는 환경에서 실행합니다. Chromium 실행 경로는 `CHROMIUM`으로 지정할 수 있습니다.

```sh
python3 -m pip install playwright
python3 tests/verify_safety.py
```

이 테스트는 가상 마이크와 합성 문장으로 녹음·저장·내보내기·삭제와 오류 복구를 확인합니다. 실제 기기의 마이크 권한, 백그라운드 처리 및 파일 저장 동작은 별도 검증이 필요합니다.

이전 `main`의 README는 기존 검증 스크립트의 62개 항목 통과를 기록합니다. 해당 스크립트는 저장소에 없어 이번 브랜치에서는 위의 회귀 테스트를 실행했습니다. 이전 `main`의 화면 가로 넘침 수정도 포함되어 있습니다.
