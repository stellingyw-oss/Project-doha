## 1. v0.1.1 변경 내역 (P0 수정 5건)

| # | 문제 | v0.1.1에서 어떻게 고쳤나 |
|---|---|---|
| 1 | 이야기를 끝내거나 화면을 떠나도 마이크(녹음)가 계속 잡혀 있었고, 권한을 거부해도 버튼이 "듣는 중"처럼 보였다 | 화면 이탈(`cvBack`·`mvBack`·`homeBtn2`·`alBack`·`endStory`), 탭 숨김(`visibilitychange`), 페이지 종료(`pagehide`·`beforeunload`)에서 `stopMic()`이 반드시 실행되어 **모든 트랙을 정지**한다. 권한 대기 중에 화면을 떠나면 늦게 도착한 스트림도 즉시 놓아준다. 거부/미지원이면 `state.micOn=false`로 두고 버튼은 회색(off) 상태, 상태 문구는 "텍스트 모드 · 마이크 권한 없이도 상상할 수 있어요"로 바뀐다 |
| 2 | 같은 날 두 번째 작품을 저장하면 첫 기록을 덮어썼고, 새로고침 뒤에는 메모리 작품만 재생되며 실제 기록 카드에는 "예시예요" 토스트가 떴다 | 작품마다 **고유 id**를 만들어 저장하므로 하루에 여러 편을 저장해도 각각 남는다. 장면·자막·그림체·녹음 원본(Blob)을 **IndexedDB**(`works` + `clips`)에 영구 저장하고, 앨범 카드를 누르면 그 편의 장면·자막·목소리가 그대로 복원·재생된다. v0.1의 `localStorage` 기록은 최초 1회 자동으로 IndexedDB로 이관된다 |
| 3 | 기본 샘플 3편이 내 기록과 섞여 편수에 포함됐다 | "내 기록"과 "예시"를 별도 영역으로 나눴다. 예시 카드는 대시 테두리 + `예시` 배지로 표시되고 내 기록 편수에 들어가지 않는다 |
| 4 | 부모 관찰 노트가 단어 매칭으로 아이의 감정·심리를 단정했다("기분을 색으로 표현하고 싶었나 봐요" 등) | 사실만 적는다. **말한 단어·바뀐 장면·바뀐 그림체·등장 요소**만 세어 서술하고, "아이의 실제 감정이나 심리 상태를 단정하지 않습니다" 고지를 상시 표시한다. 질문 예시도 사실 기반("이야기 속에 어떤 요소가 등장했어?", "아빠가 그 세상에 들어간다면 어떤 역할을 하면 좋겠어?")으로 교체 |
| 5 | 공개 저장소 README와 기본 문구에 아이의 실명·학년이 드러났다 | README는 "아이·가족" 같은 일반 표현으로 바꿨다. 앱의 기본 문구도 이름 토큰을 두어 **기본값은 "아이"**이고, 사용자가 정한 이름만 그 브라우저(localStorage)에 저장된다. 화면 어디에도 실명·나이·학년이 기본값으로 들어가지 않는다 |

### 검증 (자동)

`src/verify_v011.py` — 헤드리스 Chromium + 가짜 마이크 장치로 아래 31개 항목을 확인합니다(전부 통과).

- 같은 날 2편 연속 저장 → 2편 모두 유지, 서로 다른 id, 자막 보존
- 새로고침 → 앨범에서 과거 편을 누르면 그 편이 열리고 자막·목소리·장면 점 개수가 일치
- 실제 기록에서 "예시예요" 토스트가 뜨지 않음 / 샘플 3편 분리 및 편수 미포함
- 종료·화면 이탈·탭 숨김에서 마이크 트랙 `readyState === "ended"`
- 권한 거부 시 `micOn=false`, listening 표시 없음, 텍스트 모드 문구 표시
- 두 세션 모두 런타임·콘솔 에러 0건

```bash
python3 project-doha/src/build.py
LD_LIBRARY_PATH=/workspace/tmp/sysroot/usr/lib/x86_64-linux-gnu python3 project-doha/src/verify_v011.py
```

## 2. 바로 열어보기

| 환경 | 방법 |
|---|---|
| 컴퓨터·아이패드 | `project-doha/index.html`을 더블클릭(또는 브라우저로 드래그) |
| 아이폰 | 파일 앱에서 `index.html`을 열고, 미리보기에서 화면이 반응하지 않으면 **공유 → Safari에서 열기** |

- 이미지 4장과 그림체 미리보기 8장이 **파일 안에 base64로 내장**되어 있어, 파일만 옮겨도 그림이 깨지지 않습니다. (약 655KB)
- 인터넷 연결이 없어도 됩니다. 광고·추적·외부 요청 없음.
- 기록(장면·자막·녹음 원본)은 IndexedDB, 부르는 이름은 localStorage에만 남습니다. 브라우저 데이터를 비우면 함께 사라집니다.

## 5. 파일 구조

```
project-doha/
  index.html                 ← 최종 산출물 (이미지 내장, 단일 파일)
  assets/
    scene1_livingroom.png    ← 생성 원본 4장 (1672×941)
    scene2_space.png
    scene3_giant.png
    scene4_spaceship.png
    web/                     ← 내장용으로 줄인 JPEG + 그림체 미리보기 8장
  src/
    index.src.html           ← 원본 소스 ({{IMG_*}}, {{T_*}} 자리표시자, [[NAME]] 이름 토큰)
    prepare_assets.py        ← 원본 PNG → 웹용 JPEG + 그림체 썸네일 생성
    build.py                 ← 소스를 base64 내장 단일 index.html로 빌드
    check.py                 ← 3개 화면 크기에서 전체 흐름 자동 점검 + 스크린샷
    verify_v011.py           ← v0.1.1 P0 검증(저장·복원·마이크·권한 거부)
    test2.py                 ← 그림체 시트·마이크·영화 종료·앨범 저장 점검
    shots.py                 ← 검토용 스크린샷 촬영
```

### 수정하는 방법

1. `src/index.src.html` 수정 → `python3 project-doha/src/build.py`
2. 그림체 썸네일·이미지를 바꾸려면 `python3 project-doha/src/prepare_assets.py` 먼저 실행 후 빌드
3. 문구·색·장면을 바꾸는 곳은 `index.src.html`의 `STYLES` / `CHIPS` / `SCENE_INFO` / CSS 변수(`:root`)

### 저장 구조 (IndexedDB `doha-universe`)

| 스토어 | 키 | 내용 |
|---|---|---|
| `works` | `id` | 작품 메타(번호·날짜·제목·그림체·태그·관찰 노트·질문·메모) + 장면 배열(장면 키·자막·틴트·그림체·음성 길이·`clipId`) |
| `clips` | `id` | `workId`별 녹음 원본 `Blob` |

## 6. 함께 써볼 때 체크할 것

1. 시키지 않아도 다음 장면을 말하는가
2. 자기 상상이 화면이 되는 걸 재미있어 하는가 (어떤 그림체에서 오래 머무는가)
3. 대화가 더 풍성해지는가 (어른이 끼어들 여지가 있는가)
4. 끝난 기록을 다시 보고 싶어 하는가
5. 다른 보호자가 돈을 낼 것 같은가

## 8. 안전·개인정보 원칙

- 광고·외부 링크·보상 시스템 없음
- 심리 진단·점수·평가 문구 없음 — 관찰 노트는 사실 기록만, "심리 상태를 단정하지 않습니다" 상시 표시

- 이미지·목소리는 이 파일 밖으로 나가지 않음
- 이 저장소와 앱 기본값에는 아이의 실명·나이·학년이 들어가지 않음 (이름은 사용자가 입력한 경우에만 그 브라우저에 저장)
