### 1-1. 소스 오브 트루스 정리 (가장 큰 구조 변경)

이전에는 빌드 소스 `src/`가 `.gitignore`에 있어 저장소에 없었습니다. 그래서 PR은 빌드 산출물 `index.html`을 직접 고쳤고, 우리가 `build.py`를 한 번 돌리면 PR 변경이 전부 사라질 수 있었습니다.

- `.gitignore`에서 `src/`를 풀어 **`src/index.src.html` · `build.py` · 검증 스크립트를 저장소가 함께 관리**합니다(인쇄용 원본 PNG `assets/*.png`만 계속 제외, 빌드 입력 `assets/web/`는 포함).
- PR의 `index.html` 변경을 **`src/index.src.html`로 이식**한 뒤 `build.py`로 재빌드했습니다.
- 이식 누락을 막기 위해 **PR 빌드와 우리 빌드를 data URI만 치환해 대조**했고, 재구성한 소스로 다시 빌드한 결과가 PR 산출물과 **바이트 단위로 일치**함을 확인했습니다(699,381 bytes).
- `src/check_build.py` — `index.src.html`로 빌드한 결과가 커밋된 `index.html`과 다른지 **즉시 알려주는 검사**(드리프트 방지). 테스트 앞단에서 같이 돌립니다.

### 1-2. PR #1에서 가져온 것 (요약)

- **정직성 라벨**: `🛡 이 브라우저에만 저장`, `예시 필터 ·`, `예시 그림 ·`, 홈 `예시 장면`, 크레딧 `예시 필터`, "음성 자동 자막은 아직 없어요" 안내. **가짜 파형·가짜 "그리는 중" 지연·강제 공룡 첫 장면 제거**(중립 화면에서 시작, 예시 장면은 `예시 장면 둘러보기` 안으로).
- **녹음 전 동의 확인**: 마이크를 켤 때 `보호자와 아이 모두 지금 목소리를 이 브라우저에 녹음하는 데 동의하나요?`
- **녹음 수명주기**: recorder가 먼저 성공해야 `micOn`, 트랙 `ended` → `stopMic()` 한 경로, `onerror`/예상 밖 `onstop` 처리, `stopMic()` 멱등, 5초 타임아웃 시 유실 고지, AudioContext 노드 disconnect, Blob MIME 보존.
- **저장 정합성**: `expectedClips` + `blob.size>0`만 인정, 기존 기록이 있으면 `SAVE_FAILED`(음성을 조용히 메타-only로 격하하지 않음), `allWorks()`가 IDB+localStorage 폴백을 병합, 마이그레이션 **스냅샷 비교** 후에만 원본 삭제, `deleting`/`openSeq` 동시성 가드.
- **영화 화면 원본 음성 패널 `#originalAudio`**: 테이크별 `<audio controls>` + "원본 N 다운로드", 재생 시 영화 자동 정지.
- **내보내기 2종**: `기록 + 음성 JSON` / `기록 정보 JSON`(metadataOnly, `-metadata.json`), manifest에 `missingAudioClipCount`.
- 아빠 노트 **자동 저장 제거**(아래 저장 버튼으로 확정), 영화 **자동 재생 제거**(사용자가 재생), 카드 썸네일 중립 장면은 배경 없음.

### 1-3. v0.1.3에서 새로 만든 것

| 기능 | 동작 |
|---|---|
| **캔버스 바로 듣기** | 지금 보고 있는 장면에 녹음 테이크가 있으면 캔버스 왼쪽 아래에 **`▶ 방금 녹음 듣기`** 가 나타나고, 누르면 즉시 재생·`⏸ 멈추기`로 바뀝니다. 재생이 끝나면 라벨이 스스로 돌아오고, **마이크를 다시 켜거나 화면을 떠나거나 다른 장면으로 옮기면 자동 정지**합니다. 영화 화면 `#originalAudio`와는 서로 멈춰 동시에 재생되지 않습니다. 테이크가 없는 장면에서는 버튼이 숨겨집니다. |
| **임시 음성 자막 변환 (기본 OFF)** | 캔버스 안내줄의 토글 **`음성 자막 변환 (임시 · 브라우저 서버 전송 가능)`**. **기본값은 꺼짐**이고, 보호자가 직접 켰을 때만 `SpeechRecognition \|\| webkitSpeechRecognition`(`ko-KR`, `interimResults`, `continuous`)을 시작합니다. 확정된 말은 `suggestScene()`이 고른 **`예시 그림 ·` 장면**으로 남습니다. **원본 녹음(MediaRecorder → IndexedDB)과 완전히 분리**되어 있어 오류·미지원이어도 녹음·저장은 멈추지 않습니다. |
| **버전 표기** | meta·홈 표기·내보내기 `formatVersion` 모두 **0.1.3**. PR 로드맵의 `P1 / v0.2`(정식 한국어 음성 인식)와 구분하기 위해 이번 STT는 "임시·기본 OFF·예시 그림"으로만 표기합니다. |

### 1-4. 두 갈래가 부딪히던 지점과 결정

| 충돌 | 결정 |
|---|---|
| 강제 첫 장면 + 키워드 매핑 vs 정직한 "예시" 모델 | **정직 모델을 기준**으로 삼고, `guess()`를 **`suggestScene()`으로 되살려** "예시 그림" 라벨이 붙는 제안으로만 사용(칩과 STT가 같은 함수를 공유) |
| 녹음이 "예시 그림" 장면에 붙는 문제 | 목소리는 예시 그림에 붙이지 않고 **자막 없는 중립 장면**에 따로 보관(원본과 예시의 분리) |
| 영화 자동 재생 vs 수동 재생 | **수동 재생**(PR). "끝나고 바로 확인" 동선은 **바로 듣기** 버튼이 담당 |
| 아빠 노트 자동 저장 vs 저장 버튼 | **저장 버튼 확정**(PR) |
| 같은 "v0.1.2"가 서로 다른 동작을 가리킴 | 통합 결과를 **v0.1.3**으로 올려 구분 |

## 2. 저장 상태 · 실패 처리 (v0.1.2부터 이어진 규칙, PR에서 더 엄격해짐)

| 상태 | 뜻 | 화면 |
|---|---|---|
| `SAVING` | 원본 음성 수집·IndexedDB 쓰기 진행 중 | "저장하는 중" 오버레이, 저장 버튼 잠금, 화면 전환 차단 |

| `SAVE_FAILED` | 아무것도 확인되지 않음(기존 기록이 있으면 덮어쓰지도 않음) | 빨간 배너 + `다시 저장` · `파일로 내려받기`, 앨범에 넣지 않음 |

"행은 있는데 빈 Blob"은 저장 성공으로 세지 않습니다(`expectedClips` + `blob.size>0`).

## 5. 화면별 기능 (v0.1.3)

**화면 1 · 홈**
- 가제/슬로건, 오늘의 그림체 8종 선택(3D 애니메이션 · 동화책 · 클레이 · 블록 월드 · 모험 만화 · 실사 영화 · 크레파스 · 픽셀 월드) — 배지에 `예시 필터` 표기
- "상상 시작하기" — 이야기를 만들다 만 상태면 "이어서 상상하기"

**화면 2 · 실시간 상상 캔버스**
- **중립 화면에서 시작**(강제 첫 장면 없음), 예시 장면은 `예시 장면 둘러보기` 안의 칩 8종
- 직접 입력한 문장은 **그대로 자막**이 되고 중립 장면으로 남음
- 마이크 파형: 허용 시 실제 입력 레벨, 거부/미지원 시 평평한 대기 + 텍스트 모드 안내(가짜 파형 없음)
- 마이크를 켤 때 **보호자·아이 동의 확인**, 같은 장면에서 여러 번 녹음해도 **테이크마다 따로 보관**
- **`▶ 방금 녹음 듣기`** — 현재 장면의 마지막 테이크를 즉시 재생
- **`음성 자막 변환 (임시 · 브라우저 서버 전송 가능)`** — 기본 OFF 토글
- 상단: `🛡 이 브라우저에만 저장`, `예시 필터 · …`, 경과 시간, "이야기 끝내기 →"

**화면 3 · 상상 영화 (MY MOVIE)**
- 인트로 크레딧 → 장면별 자막 타임라인(사용자가 재생) → 엔딩 카드
- **원본 목소리 카드**: 테이크별 재생 + `원본 N 다운로드`(MIME에 맞는 확장자), 녹음 오류가 있었으면 그 사실을 표시
- "오늘의 한 줄", 등장 요소 태그, **사실만 적는 관찰 노트**(직접 입력한 문장 수·재생 가능한 원본 녹음 구간 수) + 열린 질문 2개
- 아빠의 기록 → **저장 버튼으로 확정**
- 저장 상태 배너(`다시 저장` · `파일로 내려받기`)

**화면 4 · MY UNIVERSE**
- **내 기록**: 카드마다 `기록 + 음성 JSON` · `기록 정보 JSON` · `삭제`, 상단에 `전체 기록 내보내기 (JSON)`

```
  tests/
    README.md                ← 테스트 실행 환경 안내
    verify_safety.py         ← PR #1 실패 경로 스위트
  assets/
    scene1_livingroom.png …  ← 생성 원본 4장 (저장소 제외, 로컬 보관)
    web/                     ← 빌드 입력 JPEG 4장 + 그림체 미리보기 8장

    index.src.html           ← 원본 소스 ({{IMG_*}}, {{T_*}} 자리표시자, [[NAME]] 이름 토큰)
    build.py                 ← 소스를 base64 내장 단일 index.html로 빌드
    check_build.py           ← 커밋된 index.html이 소스와 어긋났는지 검사
    prepare_assets.py        ← 원본 PNG → 웹용 JPEG + 그림체 썸네일 생성
    verify_v011.py           ← v0.1.1부터 이어진 P0 회귀 검증(32)

    check.py / shots.py / test2.py  ← 수동 점검·스크린샷 도구
```

### 수정하는 방법

1. `src/index.src.html` 수정 → `python3 src/build.py` → `python3 src/check_build.py`
2. 그림체 썸네일·이미지를 바꾸려면 `python3 src/prepare_assets.py` 먼저 실행 후 빌드
3. 문구·색·장면을 바꾸는 곳은 `index.src.html`의 `STYLES` / `CHIPS` / CSS 변수(`:root`), 장면 제안 규칙은 `suggestScene()`

### 저장 구조 (IndexedDB `doha-universe`)

| 스토어 | 키 | 내용 |
|---|---|---|
| `works` | `id` | 작품 메타(번호·날짜·제목·그림체·태그·관찰 노트·질문·메모) + 장면 배열(`key`·`caption`·`source`·`tint`·`styleId`·`audioDur`·`clipIds`·`takeCount`) |
| `clips` | `id` | `workId`·`sceneIndex`·`takeIndex`·`startedAt`별 녹음 원본 `Blob` + MIME·길이 |

`source` 값: `typed`(직접 입력) · `recording`(목소리 전용 중립 장면) · `sample`(예시 그림) · `legacy`(이관된 옛 기록).

## 8. 안전·개인정보 원칙

- 광고·외부 링크·보상 시스템 없음. 심리 진단·점수·평가 문구 없음 — 관찰 노트는 사실 기록만.
- 모든 데이터는 기기 안에만 저장(IndexedDB/localStorage). 이미지·목소리는 **사용자가 직접 내보내기를 누를 때만** 파일로 나감.
- **예외 하나를 명시합니다**: 캔버스의 `음성 자막 변환 (임시)` 토글을 **보호자가 직접 켠 경우에만** 브라우저 내장 음성인식을 쓰며, 이때 오디오가 **브라우저 제조사(Chrome/Google, Safari/Apple 등) 서버로 전달될 수 있습니다.** 기본값은 꺼짐이고, 새로고침하면 다시 꺼진 상태로 시작합니다. **원본 녹음은 이 기능과 무관하게 이 브라우저에만 저장**됩니다.
- 이 저장소와 앱 기본값에는 아이의 실명·나이·학년이 들어가지 않음 (이름은 사용자가 입력한 경우에만 그 브라우저에 저장).
- 저장소·이슈·스크린샷·테스트 픽스처에 실제 아동의 이름·음성·전사·이미지를 넣지 않음 (`AGENTS.md`).
