# PROJECT DOHA — MASTER BRIEF v1.0

2026-11-25 | 제품 기준 초안 | 공개 저장소용 (개인정보 제외)

## 1. ORIGIN
한 아빠는 아들이 꼬리에 꼬리를 물며 상상을 이야기할 때 함께 웃고, 그 세계를 눈앞에서 볼 수 있으면 좋겠다고 생각했다. 아이의 모습은 사진으로 남지만 그 나이의 목소리와 상상, 부모와 나눈 대화는 쉽게 잊힌다. 단 한 아이를 위한 선물에서 출발한다. 실제 가족의 신원이나 원본 대화는 공개하지 않는다.

## 2. 브랜드 철학
- 사진은 너의 모습을 기억하고, 우리는 너의 세상을 기억한다.
- 아이는 자라고, 상상은 남습니다.
- 아이를 더 빨리 성장시키기 위해서가 아니라, 지금의 아이를 더 오래 기억하기 위해서.
- 기록을 위한 놀이가 아닌, 놀이를 통한 기록.
- 이해는 판단이 아니다. 기술은 교감을 대신하지 않는다.

## 3. 제품 정의
아이와 부모가 평소처럼 대화하고, 옆에 놓인 태블릿에 상상 세계가 펼쳐지는 가족용 서비스. 아이의 말과 유머를 살려 시각화하고, 종료 후 원본 목소리·대화·작품·부모의 메모를 하나의 기록으로 보존한다. 아이의 상상은 원작이며 AI는 연출 도구다. 이름·가격·출시 일정은 미확정.

## 4. 핵심 경험
1. 보호자와 아이가 녹음 및 처리에 동의한 뒤 버튼 한 번으로 시작. 마이크 상태는 명확하게 표시.
2. 대화가 자연스럽게 이어진다. AI는 말을 걸거나 숙제를 주거나 평가하지 않는다. 멈춤을 재촉하지 않는다.
3. 실제 발화에 맞춰 장면을 만들고 앞 장면의 캐릭터·세계관·유머를 유지한다. 안전한 결과만 표시한다. 오류·지연은 숨기지 않는다.
4. 그림체를 미리 선택하거나 원할 때 변경한다. 우선 후보: 3D 애니메이션, 수채화 동화책, 클레이, 블록 월드. 기존 필터는 실제 생성 방식과 명확히 구분한다.
5. 종료 시 녹음·음성 인식·생성 요청을 정리한다. 원본과 AI 편집본을 분리하여 저장하고 개별 재생, 내보내기, 삭제를 지원한다.
6. 부모 공간에는 발화로 확인 가능한 관찰과 열린 질문만 제공한다. 심리 진단 및 성격·감정 단정은 하지 않는다.

## 5. UX 원칙
가로 태블릿 우선, 모바일도 지원. 화면 대부분은 상상 영역. 최초 화면에는 특정 소재를 강제하지 않는다. 그림체 기본값으로 설정 반복을 줄인다. 텍스트 입력은 접근성·실패 시 대안이다. 실시간 연속 영상은 장기 목표이며, 초기에는 안전한 연속 이미지와 간단한 움직임으로 검증한다. 샘플 모드는 실제 작품과 구분하고 생성되지 않은 화면을 생성된 것처럼 표시하지 않는다.

## 6. 안전·데이터
보호자 동의와 아이의 의사 존중, 명시적 녹음 시작/종료, 화면 이탈 시 해제. 아동의 원본 음성·텍스트·이미지·이름·식별자·기기 데이터는 공개 저장소와 로그에 금지. 외부 AI 전송 전 데이터 처리 조건·보존·삭제·학습 제외·법적 요건을 검토하고 동의 UX 및 검증을 완료한다. 실제 아동 데이터로 검증하지 않고 합성 테스트 데이터를 사용한다. 생성 전후 안전 검증과 장애 시 차단을 설계한다. 위험한 상상 자체를 아이의 심리 문제로 간주하지 않는다. 가족 전용 접근, 삭제·내보내기·백업을 지향한다. 브라우저 저장은 영구 보존으로 홍보하지 않는다. API 키는 서버 측 비밀 관리. 광고·공개 SNS·낯선 사람과의 소통·중독성 보상은 제외한다.

## 7. 단계별 로드맵 (목표, 미검증)
- P0 / v0.1.2: 원본 녹음과 저장 안전, 다운로드·삭제, 정직한 샘플 표시, 강제 시작 장면 제거, 회귀 테스트.
- P1 / v0.2: 한국어 음성 인식과 연속 대화 맥락 처리. 우선 가상 데이터, 외부 처리 기본 비활성. 지원하지 않는 환경 명확히 표시.
- P2 / v0.3: 실제 이미지 생성, 캐릭터 일관성, 그림체 3~4종, 안전 게이트, 비용·지연 측정.
- P3 / v0.4: 장면 움직임, 영화 편집 및 원본 음성 재생, 별도 작품 내보내기.
- P4 / v0.5: 가족 전용 저장·복원·장기 백업·성장 앨범, 타임캡슐과 연간 책.
- P5 / v0.6 이후: 아동심리 전문가 자문·검증, 소수 가족 베타, 사업성 검증. 단계별 법적·안전 검토 후 출시 판단.

## 8. 성공 기준
아이가 스스로 이야기를 이어가는가? 구현된 결과를 재미있어하는가? 화면이 부모와의 대화를 방해하지 않는가? 부모가 원본을 간직하고 싶어 하는가? 다른 가족도 반복 사용과 지불 의향을 보이는가? 화면 체류 시간을 성공 기준으로 삼지 않는다. 초기 실험은 가상 이야기로 시작한다. 생성 시간·비용·실패율은 실측 후 기준을 합의한다. 구독·실물 앨범은 사업 가설이며 가격 미확정.

## 9. 변경 관리
이 문서는 제품 방향의 v1.0 초안이다. 기능·기술·가격 변경은 버전과 근거를 기록한다. 철학 변경, 실제 아동 데이터 처리, 유료 API·외부 서비스 연결, 공개 배포는 창업자의 검토를 거친다.
