## 4. 통과하지 못했거나 확인하지 못한 것 (정직하게)

1. **아이패드·아이폰 Safari 실기기 미검증** — 이 컨테이너에서는 실행할 수 없다. 특히 `AudioContext` 예약 재생과 화면 잠금 뒤 복귀는 실기기에서 확인해야 한다.
2. **실제 음성 인식 없음** — 자막은 모의다. 늦은/누락 도착을 **시뮬레이션**으로 재현했고, 실제 STT 지연 분포와는 다르다.
3. **실제 마이크 대화 중 자막 지연** — 재생 중 계속 말하기는 입력 폼으로 대신했다. 마이크를 켠 채 대화하며 자막이 늦게 오는 경우는 v0.2-A에서 확인해야 한다.
4. **그림체 반영은 예시 필터 수준** — 실제 생성 이미지에 그림체가 적용되는지는 v0.2-B에서 확인.
5. **소리 품질** — 합성 음성은 말소리가 아닌 '삐-' 파형이다. 음성 인식 품질·아이 발음은 이 실험으로 판단할 수 없다.
6. **iOS 잠금 화면·백그라운드** — 화면이 가려지면 실험 재생을 멈추도록만 했다(안전 기본값). 백그라운드 재생은 지원하지 않는다.

## 5. 비용·개인정보

- **비용 0원**: 외부 API 호출·유료 모델·네트워크 전송 없음. 테스트가 외부 요청 0건을 확인한다.
- **아동 데이터 없음**: 합성 음성과 가상 대본만 사용. 실제 아이 이름·목소리·전사·사진을 저장소·테스트·스크린샷에 넣지 않았다(합성 음성 WAV도 저장소에 커밋하지 않음 — 브라우저 메모리에서만 만든다).
- **저장**: 실험 기록은 IndexedDB에 쓰지 않는다(기존 `doha-universe` 스키마 무변경). 화면을 벗어나면 실험 오디오를 멈추고, 페이지를 닫으면 사라진다.
- **정직성**: 모든 화면에 `모의 자막 · 예시 그림`, 안내문에 `합성 음성(삐- 소리)`·`실제 아이 목소리 아님`을 표시한다.
