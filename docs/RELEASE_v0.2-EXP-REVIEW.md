## 3-A. v0.2-A — 한 번에 이어 녹음 + resume() 보완 (2026-11-25 추가)

ChatGPT 검토 답변(2026-11-25 15:46) 순서에 따라 두 가지를 먼저 처리했습니다.
**① 재생 상태 보완 → ② 성인이 세 문장을 한 번에 이어 녹음.** 실기기(아이패드 가로 → 아이폰 세로)는 여전히 미검증입니다.

### ① `AudioContext.resume()` 보완 (`tikiPlay`)

| 이전 | 지금 |
|---|---|
| `ctx.resume()` 의 Promise를 기다리지 않고 곧바로 예약 + `#expState`를 "재생 중"으로 바꿈 | resume 완료를 기다리고, **실제 `ctx.state === "running"`이 된 뒤에만** "재생 중"으로 바꿈 |
| resume 실패해도 "재생 중"으로 보임(무음) | 실패하면 **"재생 준비 실패"** 로 남기고 `#expRetry` 안내 + `▶ 다시 시도` 로 다시 누를 수 있음 |
| 두 번 누르면 예약이 겹칠 수 있음 | `phase="starting"` 동안 같은 클릭은 같은 Promise를 돌려줌(예약 3개 유지) |

- `tikiResume()`: `state==="running"`이면 즉시 성공, 아니면 `resume()` 호출 → 완료 후 최대 480ms 동안 `state`를 다시 확인(사파리에서 상태 반영이 늦는 경우) → 2.5초 안에 `running`이 아니면 실패.
- 실패 사유는 로그에 남기고 화면에는 사람이 읽을 문장으로 표시합니다(`resume_rejected`, `state_still`, `resume_timeout` 등).
- 검증: `src/verify_v02a.py` A-1/A-2 (지연 900ms · 실패 · 재시도 · 완주).

### ② 성인이 세 문장을 '한 번에 이어' 녹음하고 세 마디로 나누기

| 요소 | 상태 |
|---|---|

| 나누기 | **실제 동작** — 20ms 창 RMS로 목소리/조용함을 가르고, **조용한 구간 두 곳**을 경계로 사용. 못 찾으면 대본 길이 비율로 나누고 화면에 **`경계 자동 추정`** 표시 |

| 두 번째 자막 늦게 | **모의** — 3번째 마디가 시작된 0.3초 뒤에 2번째 모의 자막을 보냄. 2번째 마디에만 `늦게 도착`으로 붙고, 마디 오디오·구간·원본은 바뀌지 않으며 그 상태가 저장됨 |
| 자막 자체 | **모의** — 실제 음성 인식 아님(외부 STT 없음, 비용 0원) |

**통과 기준 확인(새로고침 뒤 두 번째 장면)**

1. 새로고침 → `#s-expa` 목록에 녹음 1건·마디 3개가 DB에서 복원됨

## 4. 통과하지 못했거나 확인하지 못한 것 (정직하게)

2. **실제 음성 인식 없음** — 자막은 모의다. 늦은/누락 도착을 **시뮬레이션**으로 재현했고, 실제 STT 지연 분포와는 다르다.
3. **실제 마이크 대화 중 자막 지연** — 재생 중 계속 말하기는 입력 폼으로 대신했다. 마이크를 켠 채 대화하며 자막이 늦게 오는 경우는 v0.2-A에서 확인해야 한다.
4. **그림체 반영은 예시 필터 수준** — 실제 생성 이미지에 그림체가 적용되는지는 v0.2-B에서 확인.
5. **소리 품질** — 합성 음성은 말소리가 아닌 '삐-' 파형이다. 음성 인식 품질·아이 발음은 이 실험으로 판단할 수 없다.
6. **iOS 잠금 화면·백그라운드** — 화면이 가려지면 실험 재생을 멈추도록만 했다(안전 기본값). 백그라운드 재생은 지원하지 않는다.

## 5. 비용·개인정보

- **비용 0원**: 외부 API 호출·유료 모델·네트워크 전송 없음. 테스트가 외부 요청 0건을 확인한다.
- **아동 데이터 없음**: 합성 음성과 가상 대본만 사용. 실제 아이 이름·목소리·전사·사진을 저장소·테스트·스크린샷에 넣지 않았다(합성 음성 WAV도 저장소에 커밋하지 않음 — 브라우저 메모리에서만 만든다).
- **저장**: 실험 기록은 IndexedDB에 쓰지 않는다(기존 `doha-universe` 스키마 무변경). 화면을 벗어나면 실험 오디오를 멈추고, 페이지를 닫으면 사라진다.
- **정직성**: 모든 화면에 `모의 자막 · 예시 그림`, 안내문에 `합성 음성(삐- 소리)`·`실제 아이 목소리 아님`을 표시한다.
