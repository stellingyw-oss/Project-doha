### A. 톤 리뉴얼 요약
- 배경: `#120F0B`(검정) → `#FEF8EC`(바닐라 크림). 본문 잉크 `#22303D`, 포인트 앰버·코랄·스카이.
- 홈: 종이 액자에 붙인 대표 그림, 도톰한 앰버 3D 시작 버튼, 그림체 고르기 카드 1장.
- 캔버스: 무대만 크림 액자(6px) + 따뜻한 밤하늘로 남기고, 나머지 컨트롤은 흰 카드 톤.
- 영화·앨범: 크림 극장 프레임 + 흰 카드. 연간책·타임캡슐도 같은 종이 톤.
- 메타: `doha-version 0.1.4`, `theme-color #FEF8EC`, iOS 상태바 `default`, `color-scheme: light`.
- **그대로 둔 것**: 정직성 라벨 5종, 녹음 전 동의 확인, `▶ 방금 녹음 듣기`, 음성 자막 변환 기본 OFF,
  `#originalAudio` 원본 목소리 카드, 저장·내보내기·개별 삭제, 홈 `예시 장면` 배지,
  **시작 직후 장면 0개의 빈 무대**(예시 장면 강제 없음).

### B. 내보내기 음성 누락 경고
- 원인: `missingAudioClipCount`가 파일 manifest에만 적히고, 화면은 "기록을 파일로 내보냈어요" 성공 안내만 띄웠습니다.
- 수정: 파일 `manifest.missingAudioClipCount` · `manifest.missingAudioNote` · `note`에 누락 문장을 남기고,
  화면은 경고 토스트("파일로 내보냈지만 원본 음성 N구간이 빠졌어요 — 장면과 기록은 그대로 담겼어요")를 띄웁니다. 개별·전체 내보내기 모두.

### C. 영화 ▶ 재생 버그
- 원인: 제목 카드 `.intro`(`z-index:9`)가 재생 바 `.mv-chrome`(`z-index:8`)를 덮고 있었습니다.
  눌러도 재생이 시작되지 않았고, 카드 배경이 불투명해서 ▶ 가 **보이지도 않았습니다.**
- 수정 두 줄:
  1. **`.intro{pointer-events:none}`** — 제목 카드는 보여주기만 하는 판이라 클릭을 통과시킵니다.
  2. **`.mv-chrome` z-index `8 → 10`** (끝 화면 `.ended` `10 → 11`) — 제목 카드가 떠 있는 동안에도
     ▶ 와 진행 바가 카드 위에 그려져 **눈에 보입니다.** 클릭만 통과시키고 화면에 안 보이면
     사람은 누를 곳을 찾을 수 없어서, 보이는 것까지 함께 고쳤습니다.
  3. 무대가 낮은 화면(폰 390×844 등, `max-width:560px` 또는 `max-height:560px`)에서는
     제목 카드 아래를 비우고 글자를 줄여(`padding:8px 12px 72px`, `.rule` 숨김) 카드 글이
     진행 바와 겹치지 않게 했습니다.
- v0.1.2 라이브와 v0.1.3 `main` 빌드에도 있던 기존 문제이며, 이번 CSS 변경과는 무관합니다.
- 재현/대조: 같은 검사 로직을 수정 전 빌드와 수정 후 빌드에 적용했습니다.
  - 수정 전: `elementFromPoint` 결과가 `#mvIntro`, 실제 마우스 클릭이 "다른 요소가 가로챔"으로 실패,
    ▶ 자리 픽셀이 제목 카드 보라색(거리 357)
  - 수정 후: 히트 대상이 `path`(재생 버튼 내부), 실제 클릭 수락, 재생 시작(아이콘·타임코드·진행바 변화),
    ▶ 자리 픽셀이 크림색(거리 13.6), 제목 카드 글자와 컨트롤 바가 겹치지 않음(네 해상도 모두)

## 4. 아직 검증하지 않은 것 (미검증으로 표기)

- **실기기 Safari / 아이패드 터치 실측**: 위 수치는 전부 로컬 headless Chromium(가짜 마이크) 결과입니다.
  iOS Safari의 `pointer-events`, 오디오 자동재생 정책, safe-area, 상태바 색은 실기기에서 눈으로 봐야 합니다.
- **실제 마이크·권한 다이얼로그**: 가짜 장치로만 확인. 실제 iOS 권한 거부/허용 UI는 미확인.
- **음성 자막 변환(STT) 실서버 품질**: 기본 OFF 상태만 확인. 실제 인식 품질은 미측정.
- **영상·목소리 합성, 부모 리포트**: 원래 v0.4 / v0.6 로드맵, 이번에도 미구현.
